# Cova Para Um — Download

Instalador oficial para Windows 64 bits.

[Baixar Cova Para Um](https://github.com/gabrielfeelix/cova-para-um-downloads/releases/latest/download/CovaParaUm-Setup-0.1.0.exe)

[Jogar no navegador](https://cova-para-um.vercel.app/)

Baixe o arquivo `.exe`, abra-o e siga o instalador. O jogo completo, o ícone e os atalhos já estão incluídos. Não é necessário instalar Node.js ou ferramentas de desenvolvimento.

O instalador ainda não tem certificado de assinatura de código. Esta é uma versão inicial para testes, com conteúdo em desenvolvimento.

Este repositório distribui somente os instaladores e suas somas SHA-256. O código-fonte é mantido em repositório privado. A disponibilidade pública do download não concede licença de redistribuição dos assets.
